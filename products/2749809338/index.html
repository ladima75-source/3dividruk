Горщик для кімнатних рослин "Ringa" з органічним візерунком, Сірий, d15×h14 см, 3D-друк, Україна Ringa — це дизайнерський акцент для сучасного інтер'єру. Його форма натхненна природними структурами та математичною симетрією. Динамічний візерунок створює враження руху, ніби поверхня жива. Матовий сірий колір підкреслює глибину фактури та робить горщик універсальним для будь-якого стилю — від джапанді до техно-лофту. Горщик виготовлено з екологічного пластику PLA або PETG на 3D-принтері. Має дренажний отвір, підходить для використання з піддоном або без нього. Тип: Горщик для квітів Матеріал: PLA або PETG пластик Колір: Сірий (можливі інші кольори) Розміри: діаметр 15 см, висота 14 см (можливі інші розміри) Спосіб виготовлення: 3D-друк Призначення: для кімнатних рослин, оздоблення інтер'єру Особливості: органічна форма, глибокий рельєф, сучасна пластика
