# 3DiViDruk — окремий інтернет-магазин

Самостійний магазин 3DiViDruk із власним каталогом, кошиком, оформленням замовлень, backend та адмінкою. Технічні підходи адаптовано з BB610 Market, але код не звертається до його даних, API, сховищ або секретів.

> Поточний статус: тестова версія. Домен `3dividruk.com.ua` не перемикався, Prom.ua залишається чинним каналом продажу, онлайн-оплата вимкнена.

- Ієрархічний каталог: настільні / підвісні світильники, окремі групи декору (чаші й органайзери, фігурки, підставки для пахощів, настінний декор), прямі посилання на підкатегорії. Схема та правила повторного імпорту: [`docs/catalog-taxonomy.md`](docs/catalog-taxonomy.md).

## Що готово

- 183 картки товарів, 1017 локальних фотографій, ціни, описи, характеристики та вихідні SKU з публічної вітрини [3dividruk.com.ua](https://3dividruk.com.ua/ua/).
- Адаптивний каталог, сторінки товарів, пошук і фільтри, кошик та оформлення тестового замовлення.
- Окремий Python backend без сторонніх залежностей і окрема SQLite-база.
- Адмінка каталогу, замовлень, історії статусів, налаштувань доставки та післяплати.
- Чернетки XML/CSV-фідів, sitemap, robots.txt, метадані й статичні сторінки.
- GitHub Pages-сумісний режим перегляду: він не створює замовлення і не передає введені дані.
- Тестовий режим за замовчуванням: без списання коштів, повідомлень покупцям і створення ТТН.

Звіт імпорту: [`data/import-report.json`](data/import-report.json). Один вихідний SKU (`SKU0285`) повторювався у двох різних картках Prom.ua, тому внутрішні торгові ідентифікатори для них розділено, а оригінальний SKU збережено для звірки.


## Нова адмінка: огляд і візуальний редактор

- **[Огляд магазину](admin/dashboard.html)** — каталог, активні й приховані позиції, готовність до запуску.
- **[Візуальний редактор](admin/workbench.html)** — перетягування карток, ↑ / ↓, редагування назви, опису та ціни, експорт локальної чернетки.
- **[Каталог і налаштування](admin/index.html)** — існуючий API-захищений розділ товарів, тестових замовлень, доставки.

На GitHub Pages редактор зберігає **лише локальну чернетку цього браузера**; зміни можна переглянути з `editorPreview=1` або експортувати в JSON. Автоматична публікація на GitHub Pages без backend не підтримується. На окремому backend редагування та порядок зберігаються у приватній SQLite-базі під адміністративним токеном. Деталі: [процес роботи з адмінкою](docs/admin-workflow.md).

## Локальний запуск магазину й адмінки

Потрібен Python 3.11 або новіший.

```powershell
$env:DIVIDRUK_ADMIN_TOKEN = '<унікальний випадковий токен щонайменше 24 символи>'
python -m backend.server
```

Після запуску:

- магазин: `http://127.0.0.1:8080/`;
- адмінка: `http://127.0.0.1:8080/admin/`.

Токен адміністратора не записується до репозиторію. Приклад змінних є в [`backend/.env.example`](backend/.env.example), а повна інструкція — у [`docs/backend-setup.md`](docs/backend-setup.md).

## Перевірка

```powershell
python tools/validate.py
node tests/storefront.cjs
python -m unittest discover -s tests -p backend_test.py -v
```

Перевірки не виконують реальних платежів і не створюють відправлень.

## Оновлення каталогу

Імпортер читає лише загальнодоступні сторінки магазину без входу, приватного API або змін на Prom.ua:

```powershell
python tools/import_prom.py
python tools/build.py
python tools/validate.py
```

Фото зберігаються локально, тому тестова вітрина не залежить від hotlink-завантаження з Prom.ua. Перед повторним імпортом варто зберегти власні правки каталогу з адмінки: безперервної двосторонньої синхронізації між каналами поки немає.

## Межі тестового релізу

GitHub Pages є лише публічною статичною вітриною. Для постійної роботи замовлень та адмінки backend треба окремо розмістити на сервері з TLS, приватними змінними оточення, резервними копіями та обмеженням доступу. До завершення перевірки не вмикайте `DIVIDRUK_TEST_MODE=0` і не активуйте приймання справжніх замовлень.

Ще не підключено: еквайринг, фіскалізацію, автоматичні повідомлення, створення ТТН, приватний Prom API та автоматичну синхронізацію залишків між Prom.ua й новим магазином.

## Походження та ізоляція

- Джерело каталогу: публічна вітрина 3DiViDruk на Prom.ua.
- Технічна основа: власний репозиторій власника `bb610-market`, адаптований у новий незалежний простір `3dividruk`.
- Runtime-база, токени й ключі ігноруються Git; жодних конфіденційних значень BB610 Market не переноситься.
- Домен і DNS не змінювалися; CNAME навмисно відсутній.
