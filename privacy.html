Цей сайт працює в тестовому режимі. Використовуйте вигадані дані при перевірці оформлення.

Тестова вітрина на GitHub Pages

Кошик зберігається локально у вашому браузері. Контактні дані з демонстраційної форми не надсилаються продавцю і не зберігаються цією програмою. Для очищення кошика видаліть товари або дані сайту у браузері.

Окремий тестовий backend

Якщо вітрина обслуговується окремим backend, тестові замовлення зберігаються у його власній базі. Доступ адміністратора захищений авторизацією. Успішне замовлення відображається лише у поточній сесії за приватним токеном.

Зовнішні сервіси

GitHub Pages як хостинг може обробляти технічні журнали запитів відповідно до власної політики. На сайті немає підключених рекламних пікселів BB610. Посилання на Prom.ua відкривають діючий магазин з його правилами обробки даних.

До запуску реальних продажів власник має затвердити реквізити, строки зберігання та остаточну політику конфіденційності.
